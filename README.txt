# Personal Portfolio Website

## Files
- `index.html` — main portfolio page
- `style.css` — complete responsive styling
- `script.js` — mobile menu, reveal animations and year

## Before publishing
Replace:
1. `Your Name`
2. `YN`
3. `yourmail@example.com`
4. LinkedIn / GitHub / Behance / Instagram `#` links
5. Demo project titles/descriptions/links
6. The profile placeholder with your photo if you want

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will generate your live portfolio URL.
